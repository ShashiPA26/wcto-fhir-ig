# Well Child Tamariki Ora FHIR Implementation Guide

This Implementation Guide defines common FHIR and integration patterns for digital Well Child Tamariki Ora (WCTO) services.

The initial implementation supports **WCTO Core Contact 8 — the B4 School Check (B4SC)**.

The guide is intended to support provider organisations working within their existing clinical systems while interacting with national digital services and structured FHIR forms.
